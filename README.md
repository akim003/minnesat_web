## MinneSat Team Website

A modern full-stack website for the University of Minnesota’s AIAA CanSat Team **MinneSat**, designed to highlight competition achievements, attract sponsors, and streamline member recruitment.

### Features
- Dynamic project galleries and competition result pages  
- Sponsor management and recognition components  
- Mobile-first responsive UI with Tailwind CSS and shadcn/ui  
- Image optimization and fast global delivery on Vercel  
- Form handling with React Hook Form + Zod  
- Custom design system using UMN maroon/gold branding  

### Tech Stack
- **Framework:** Next.js 15, React 19, TypeScript  
- **Styling:** Tailwind CSS, shadcn/ui  
- **Deployment:** Vercel  
- **Validation & Forms:** React Hook Form + Zod  

Actively deployed and version-controlled to support ongoing team operations.
